Get started in 5 minutes

Windows 10/11 · Python required · iPhone or Android

1

Install Python

Download from python.org. Check "Add Python to PATH" during install.

2

Download SimTrack

Download and extract the zip, then double-click start.bat. Dependencies install automatically on first run.

3

Open on your phone

The SimTrack window shows a URL — open it in Safari (iPhone) or Chrome (Android) on the same WiFi. Allow camera access.

4

Enable in game

In your game settings set head tracking to FreeTrack. Start SimTrack before launching the game.

5

Calibrate

Sit in your normal position, look straight ahead, tap Calibrate on the phone page. Done.

How it works

All processing is local — nothing leaves your network

# 1. Phone browser runs MediaPipe face detection at ~30fps
# 2. Yaw / pitch / roll streamed over WebSocket (local WiFi)
# 3. PC server writes FreeTrack shared memory
# 4. Game reads shared memory — no middleware needed

Phone (Safari)  ──WebSocket──►  PC (server_windows.py)
                                    ├─ FreeTrack shared memory → AC, ETS2, BeamNG
                                    └─ UDP 4242               → OpenTrack → iRacing
